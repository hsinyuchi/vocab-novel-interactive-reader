## ✨ 核心特色與教學亮點 (Key Features)

1. **📖 11 大流行題材沉浸爽文 (Viral Pop-Culture Genres)**：
   - 告別枯燥死背！涵蓋高中職生最愛之 11 大多巴胺爆款流派：
     1. 👑 **傲嬌霸總／反差護短甜寵流**（青少女最愛爆款，智性戀反差萌）
     2. 🍳 **Netflix 黑白大廚／階級逆襲流**（老菜尾與極致火候盲測打哭評審）
     3. 🎤 **K-POP 韓團／出道生存戰流**（舞臺事故神級救場、高音 C 位絕殺）
     4. 🎬 **韓劇大女主／財閥復仇爽劇流**（慈善宴會關鍵證據當場絕殺打臉）
     5. ⚔️ **熱播陸劇／仙俠宗門大比流**（雜役靈根覺醒、一劍驚世傲慢長老震驚）
     6. 🕶️ **好萊塢特工／極限逃生電影流**（暗夜飆車、三十秒破解密碼驚天反轉）
     7. 🔍 **沉浸式劇本殺／暴風雪山莊懸疑流**（豪門孤島夜宴、不在場證明抽絲剝繭）
     8. 📺 **熱門戀綜／修羅場全網直播流**（修羅場反擊、人間清醒霸氣回懟）
     9. 🏫 **校園逆襲／重生打臉流**（時空重置、暴風作畫逆襲成神）
     10. 📜 **校園規則怪談／微恐推理流**（封閉校園守則、細思極恐智商突圍）
     11. 💼 **反差商戰／特助隱藏大佬流**（看似小實習生、實為幕後核心代碼掌門人）
   - 融入 2~4 句高衝突生動角色對話，零色情零暴力，600~800 字輕盈呼吸感排版。
2. **🎚️ 三階鷹架學習切換 (3-Stage Scaffolding)**：
   - **Step 1 學習版**：行內括號中文提示，無痛輸入。
   - **Step 2 複習版**：雙向翻牌遮罩（遮中文測字義 / 遮英文考拼字），零壓力自我檢測。
   - **Step 3 全英版**：純美語自然語音串流（Web Speech API TTS），搭配一鍵複製故事文本外掛高音質 MP3。
3. **🍱 零滑動便當盒單字卡 (Bottom Sheet Drawer)**：
   - 點擊生字即刻展開：音標、雙語釋義、實用例句一屏直觀收納。
   - 支援手機「上一步」popstate 歷史攔截，只平滑收合單字卡而不退出網頁。
4. **🎉 命運分水嶺三分支結局**：
   - 讀者抉擇引導不同走向（A/B/C 三分支結局），點擊即刻慶祝彩帶爆破，並附贈經典英文名言點睛。
5. **🎨 一課一專屬主題色 (Theme Accents)**：
   - 完全對齊 Sylvia's Hub 視覺體系，單一原生 HTML+CSS+JS 零外部依賴，可單機點擊離線閱讀，亦支援一鍵打包部署 Cloudflare Pages。
